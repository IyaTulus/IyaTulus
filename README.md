Saya adalah seorang pengembang perangkat lunak dari Indonesia yang berfokus pada sisi *Backend*. Saya sangat menikmati proses mengubah logika dan kebutuhan sistem menjadi kode yang fungsional, rapi, dan mudah dipelihara.

*   🔭 Fokus utama saya saat ini adalah pengembangan **Backend** menggunakan kerangka kerja **Laravel** (PHP).

*   🚀 Sedang aktif mempelajari konsep implementasi **Arsitektur Microservices** dan pengembangan **REST API** yang efisien.
*   🤝 Sangat terbuka untuk peluang karir *entry-level*, kolaborasi proyek, atau kesempatan untuk belajar langsung dari praktisi industri.
